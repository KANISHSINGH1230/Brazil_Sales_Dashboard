# 📊 Sales Performance Dashboard | Power BI

## 📌 Project Overview

This Power BI dashboard provides a comprehensive analysis of sales, customers, payments, reviews, and geographic performance. It helps businesses monitor key performance indicators (KPIs), identify top-performing product categories, analyze payment behavior, and understand customer distribution across different regions.

- Credit Card is the most preferred payment method.
- Health & Beauty is the highest revenue-generating category.
